1Installation

Auto UV Unwrap is a Blender extension. You get one .zip that works on every supported platform. Do not unzip it.

  1. Open Blender 4.2 or newer.
  2. Drag and drop the .zip file onto the Blender window, or go to Edit › Preferences › Get Extensions, open the ▾ menu in the top right and choose Install from Disk…
  3. Make sure Auto UV Unwrap is enabled in the extensions list.
  4. Press N in the 3D Viewport: you will see a new Auto UV tab.
The add-on preferences show whether the bundled xatlas library loaded on your system. Smart Parts and Smart UV Project work without it.

Updating

Install the new .zip the same way. Blender replaces the old version. Restart Blender if the panel does not refresh.

2Quick start

  1. Select one or more mesh objects in Object Mode, or select faces in Edit Mode.
  2. Open the Auto UV tab in the sidebar (N).
  3. Leave Engine on Smart Parts and Quality on Balanced.
  4. Click Auto Unwrap.

Seams are written to the mesh, the UVs are unwrapped and packed into 0–1, and the Results panel, the status bar and the HUD show the numbers. Not happy? Press Ctrl+Z once: UVs, seams, selection and mode all go back to how they were.

4Engines

Pick the engine from the picture gallery at the top of the panel.

EngineHow it worksUse it when
Smart Parts (default)Finds the parts of the model from its shape (sharp and concave edges, topology), flattens each part, measures the distortion and splits again only where a chart is above the target. Small charts are merged back when the stretch allows.Almost always. Fewest islands and low stretch.
xatlasChart segmentation from the bundled xatlas library, then flattened with Blender's own solver and packed.Hard-surface and CAD-like meshes, or as a second opinion. Often the lowest distortion with more islands.
Smart UV ProjectBlender's built-in Smart UV Project, run with the add-on's packing and margin.As a quick baseline to compare against.

Results

After every Auto Unwrap or Analyze UVs the Results panel lists the operation and engine, islands, seams, flipped faces, average and max distortion against the target, and the time. The same summary appears in Blender's status bar. Distortion Colors in this panel makes Analyze UVs also paint a heatmap (see next section).

7Analyze UVs

Analyze UVs measures the active UV map of the selected meshes without changing it. It works on any UVs: hand-made, from another tool, or from Auto UV.

  • Reports islands, average and max distortion and flipped faces in the Results panel and the HUD.
  • With Distortion Colors on, it also writes a color attribute named AutoUV_Distortion and switches the viewport color to Attribute so you see a heatmap on the mesh (blue = low stretch, red = high stretch).
  • In the UV Editor's Auto UV panel you can toggle Blender's own stretch overlay and its type (area or angle).

8Viewport HUD

The HUD is a small card drawn in the 3D Viewport with the latest result: engine, islands, seams, flipped faces, time, a distortion bar against your target and a mini UV layout preview.

  • Turn it on with the HUD button in the header of the Auto UV panel, or in the Viewport HUD sub-panel.
  • In Edit › Preferences › Add-ons › Auto UV Unwrap you can set:
    • Corner: Top Left, Top Right, Bottom Left (default) or Bottom Right
    • HUD Scale: 0.5–2.0, multiplied by Blender's Resolution Scale
    • HUD Opacity: background opacity, 0.2–1.0
    • Show UV Layout: show or hide the mini UV preview

The distortion bar turns from green to amber to red as the value goes from 0 to twice your target.

9Reading the results

IslandsNumber of separate UV pieces. Fewer usually means fewer visible seams in your texture.

FlippedFaces that are mirrored in UV space. Should be 0.

10Tips

  • Guide the cuts: mark a few seams where you want them (for example on the back of a character) and keep Keep My Seams on. Auto UV builds the rest around them.
  • Too many islands? Raise the distortion threshold (Custom) or use Fast. Too much stretch? Use Quality or lower the threshold.
  • Hard-surface models: lower Sharp Angle (for example 30–45°) so every hard edge becomes a seam.
  • Organic models: raise Sharp Angle or set it to 180° and let Smart Parts decide.
  • Several objects sharing one texture: select them all and keep Pack Together on.
  • Only part of a mesh: select those faces in Edit Mode. Other faces are left as they are.
  • Compare engines: unwrap, read the HUD, Ctrl+Z, switch engine, unwrap again.

11Troubleshooting

The Auto Unwrap button is greyed out

Select at least one mesh object in Object Mode, or enter Edit Mode on a mesh. Curves, text and other object types are not supported; convert them to mesh first.

"xatlas not available" in the preferences

The bundled xatlas wheel could not load on this system. Reinstall the extension from the .zip. Smart Parts and Smart UV Project keep working without it.

An object was skipped

The status bar shows a "Skipped …" warning with the reason. Other selected objects are still processed. Possible reasons:

  • shares mesh with …: two selected objects use the same mesh data (linked duplicates). The mesh is unwrapped once, through the first object.
  • linked library data: the mesh comes from a linked .blend and cannot be edited. Make it local first.
  • hidden, no faces, no faces selected (Edit Mode), no UV map (Analyze UVs).
My own seams disappeared

Existing Seams is set to Replace All, or the engine is Smart UV Project, which ignores seams. Press Ctrl+Z, set Keep My Seams and use Smart Parts or xatlas.

Packing takes very long

Pack Shape is set to Convex Hull. Switch to Exact Shape or Bounding Box (Custom Quality), or use a preset.

The HUD does not show

Turn on the HUD button in the panel header, then run Auto Unwrap or Analyze UVs once. Check the corner setting in the add-on preferences, and make sure viewport overlays are visible.

Does it need the internet or a GPU?

No. Everything runs offline on the CPU inside Blender. There is no AI model, no account and no network access.
